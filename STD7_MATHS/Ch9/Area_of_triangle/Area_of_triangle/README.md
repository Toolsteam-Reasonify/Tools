# Area of Triangle Tool

Vite + React + TypeScript + Tailwind CSS app for learning the Area of a Triangle. Mirrors the UX of the companion tools with Learn, Practice, and Real World.

## Scripts
```bash
npm install
npm run dev
npm run build
npm run preview
```

## Structure
```
src/
  contexts/LanguageContext.tsx
  features/Triangle/
```

## Notes
- Keep all user-visible strings in the language context.
- Follow Tailwind utility and animation conventions used in the suite.
