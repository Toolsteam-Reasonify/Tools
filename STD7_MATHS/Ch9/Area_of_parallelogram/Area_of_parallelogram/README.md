# Area of Parallelogram Tool

Vite + React + TypeScript + Tailwind CSS app for learning the Area of a Parallelogram with Learn, Practice, and Real World sections. Fully language-supportive (where implemented) similar to companion tools.

## Scripts
```bash
npm install
npm run dev
npm run build
npm run preview
```

## Structure
```
src/
  contexts/LanguageContext.tsx
  features/Parallelogram/
```

## Notes
- Keep user-facing strings in the language context.
- Use Tailwind utilities and existing patterns.
