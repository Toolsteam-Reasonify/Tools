# Division of Fractions Tool

An interactive educational web application for learning division of fractions, built with React, TypeScript, and Tailwind CSS.

## Features

### 🎓 Learn Section
- **Step 1**: Division of Whole Number by a Fraction
- **Step 2**: Reciprocal of a Fraction
- **Step 3**: Division of a Fraction by a Whole Number
- **Step 4**: Division of a Fraction by Another Fraction

### ✍️ Practice Section
Interactive practice questions based on Exercise 2.3:
- 12 ÷ 3/4
- Finding reciprocals
- 7/3 ÷ 2
- 2/5 ÷ 1/2
- Mixed number divisions
- Complex fraction divisions

### 🌍 Real World Examples
Six practical applications:
1. **Recipe Scaling** - Adjusting ingredient quantities
2. **Construction** - Calculating areas with fractional dimensions
3. **Study Time** - Time management calculations
4. **Discounts** - Price calculations with fractional discounts
5. **Maps & Scale** - Converting map distances to real distances
6. **Fuel Usage** - Calculating fuel consumption over time

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Navigate to the project directory:
   ```bash
   cd "D:\Reasonify data\ch_2\divison"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit the URL shown in the terminal (typically `http://localhost:5173`)

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## Educational Content

### Division Concepts Covered
1. **Whole Number ÷ Fraction**: Understanding how to divide whole numbers by fractions using the reciprocal method
2. **Reciprocals**: Learning what reciprocals are and how to find them
3. **Fraction ÷ Whole Number**: Dividing fractions by whole numbers
4. **Fraction ÷ Fraction**: Complete division of fractions by fractions

### Visual Learning
- Circle diagrams showing fractional parts
- Interactive fraction displays
- Step-by-step equation solving
- Real-world scenario applications

### Practice Questions
Based on NCERT Exercise 2.3, covering:
- Basic division problems
- Reciprocal identification
- Mixed number conversions
- Complex fraction operations
