Ch10 – Chapter 10 Examples

This folder contains multiple Vite + React + TypeScript + Tailwind examples for Chapter 10.

Subprojects:
- `ch10_10.1`
- `ch10_10.2`
- `ch10_10.3`
- `ch10_10.4`
- `ch10_10.5`
- `ch10_10.6`

How to run any subproject:
1) Open a terminal in the subproject folder, e.g. `cd ch10_10.4`
2) Install dependencies: `npm install`
3) Start the dev server: `npm run dev`
4) Build for production: `npm run build`
5) Preview the build: `npm run preview`

Notes:
- Each subproject is independent; install dependencies per folder.
- See each subproject's README for specifics if present.
