# Reasonify — Chapter 6 Projects

This directory contains multiple Vite + React + TypeScript mini-apps for Chapter 6.

## Projects

- ch6_6.4: Exterior Angles Tool
- ch6_6.5: Triangle Angle Sum Tool
- ch6_6.6: Advanced Exterior Angles Tool
- ch6_6.7: Interactive Triangle Canvas
- ch6_6.8: Pythagoras Theorem Tool

## Prerequisites

- Node.js 18+ recommended
- npm (comes with Node)

## Getting Started (per project)

1. cd into a project folder (e.g., `ch6_6.5`)
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
5. Preview the production build locally:
   ```bash
   npm run preview
   ```

## Notes

- Each subfolder is an independent Vite project with its own `package.json`.
- Build outputs are written to each project's `dist/` directory.
- For environment variables, create an `.env` file within the specific project directory as needed.
