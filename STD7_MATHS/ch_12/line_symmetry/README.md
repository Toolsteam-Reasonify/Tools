# Line Symmetry (Chapter 12)

An interactive Vite + TypeScript + Tailwind project exploring line symmetry concepts: identifying lines of symmetry, reflecting shapes, and checking for mirror symmetry.

## Prerequisites
- Node.js 18+ (or 20+ recommended)
- npm 9+

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Create production build
npm run build

# Preview the production build locally
npm run preview
```

## Tech Stack
- Vite
- TypeScript
- Tailwind CSS

## Project Structure
- `index.html`: App entry HTML
- `src/`: TypeScript/React (or vanilla TS) source files
- `tailwind.config.js`, `postcss.config.js`: Styling pipeline config
- `tsconfig*.json`: TypeScript configuration

## Notes
- If ports conflict, set a custom port with `npm run dev -- --port=5174`.
- Tailwind classes are purged in production builds via the provided config.
