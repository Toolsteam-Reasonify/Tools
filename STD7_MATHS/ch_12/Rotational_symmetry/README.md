# Rotational Symmetry (Chapter 12)

A Vite + TypeScript + Tailwind project demonstrating rotational symmetry: order of rotation, angle of rotation, and invariant appearances after rotation.

## Prerequisites
- Node.js 18+ (or 20+ recommended)
- npm 9+

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Create production build
npm run build

# Preview the production build locally
npm run preview
```

## Tech Stack
- Vite
- TypeScript
- Tailwind CSS

## Project Structure
- `index.html`: App entry HTML
- `src/`: TypeScript/React (or vanilla TS) source files
- `tailwind.config.js`, `postcss.config.js`: Styling pipeline config
- `tsconfig*.json`: TypeScript configuration

## Notes
- Configure a custom dev port if needed: `npm run dev -- --port=5175`.
- Ensure any canvas/WebGL interactions account for device pixel ratio when rotating.
