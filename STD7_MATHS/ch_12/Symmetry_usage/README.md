# Symmetry Usage (Chapter 12)

A Vite + TypeScript + Tailwind project showcasing practical uses of symmetry in design, nature, and engineering (e.g., bilateral balance, tessellations, logos, architecture).

## Prerequisites
- Node.js 18+ (or 20+ recommended)
- npm 9+

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Create production build
npm run build

# Preview the production build locally
npm run preview
```

## Tech Stack
- Vite
- TypeScript
- Tailwind CSS

## Project Structure
- `index.html`: App entry HTML
- `src/`: TypeScript/React (or vanilla TS) source files
- `tailwind.config.js`, `postcss.config.js`: Styling pipeline config
- `tsconfig*.json`: TypeScript configuration

## Notes
- To experiment with different examples, add pages/components under `src/`.
- Use Tailwind utility classes to quickly illustrate symmetric layouts.
